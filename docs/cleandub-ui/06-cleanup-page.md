## 六、页面二：清理 — 重复文件分组与安全处理

参考第二张 UI 概念图。

页面目标：帮助用户检查重复文件，明确选择保留文件，并安全地清理或隔离多余文件。

这是整个应用最重要的业务页面。

### 6.1 页面顶部

标题：

重复文件清理

说明：

查看重复文件分组，选择保留、清理或隔离。

顶部统计卡片：

- 重复文件组数。
- 可释放空间。
- 最近一次扫描时间。

提供重新扫描按钮。

重新扫描时，如果存在未完成的用户操作，先提示用户。

### 6.2 左侧文件类型筛选栏

分类：

- 全部分组
- 图片
- 视频
- 文档
- 压缩包
- 音频
- 其他

每个分类显示真实的重复文件组数。

点击分类后，右侧列表立即过滤。

顶部支持：

- 搜索文件名。
- 按文件大小排序。
- 按重复数量排序。
- 按文件类型排序。
- 按扫描路径排序。
- 选择全部分组。
- 取消全部选择。

### 6.3 重复文件分组列表

每个重复文件组采用清晰的卡片或列表布局。

展示：

- 文件类型图标或缩略图。
- 文件名。
- 重复文件数量。
- 文件大小。
- 文件格式。
- SHA-256 哈希摘要。
- 文件路径。
- 修改时间。
- 每个文件的处理状态。

图片文件：

- 使用真实缩略图。
- 点击缩略图可打开大图预览。

视频文件：

- 显示视频缩略图或文件类型图标。
- 可以显示文件大小、格式等元数据。
- 不要求完整实现视频播放器。

文档文件：

- 使用简洁的文档图标。
- 展示扩展名、大小和路径。

其他文件：

- 使用对应文件类型图标。
- 不得因文件无法预览而无法参与重复文件识别。

长文件路径需要截断显示，并通过 Tooltip 或详情面板展示完整路径。

### 6.4 重复文件识别逻辑

必须采用真实的内容校验机制。

建议采用以下流程：

第一阶段：枚举指定目录中的文件。

第二阶段：按照文件大小对文件分组。

第三阶段：对于大小相同的候选文件，计算 SHA-256。

第四阶段：只有大小相同且 SHA-256 相同的文件才进入同一个重复文件组。

第五阶段：展示实际重复文件分组。

注意：

- 文件名相同不代表文件内容相同。
- 文件名不同但内容相同的文件也必须识别出来。
- 文件大小相同不代表文件内容相同。
- 哈希计算应采用流式读取，避免一次性将大文件全部载入内存。
- 文件在扫描过程中可能被修改或删除，需要处理读取失败和文件状态变化。
- 对无法读取的文件进行记录和提示，不要直接忽略错误。
- 同一个文件不得因为多条扫描路径被重复计数。
- SHA-256 相同的文件可视为内容重复候选；执行高风险操作前仍需检查文件当前状态。

### 6.5 保留文件

每个重复文件组必须允许用户指定一个保留文件。

提供按钮：

保留此文件

行为：

1. 将该文件标记为此组的保留文件。
2. 默认不对该文件执行清理或隔离。
3. 显示清晰的“保留”标记。
4. 允许用户更改保留文件。
5. 在未明确指定保留文件时，不得对该组自动执行破坏性操作。

建议为每组重复文件默认选中一个候选保留文件，但必须明确显示这个选择只是建议，用户可以修改。

### 6.6 清理文件

危险操作按钮：

清理

按钮颜色：

#CF222E

行为：

1. 清理操作默认仅针对用户明确选中的重复文件。
2. 不得清理已标记为保留的文件。
3. 执行前显示确认对话框。
4. 对话框显示将处理的文件数量、文件路径和预计释放空间。
5. 明确说明清理可能导致数据无法恢复。
6. 再次检查文件是否存在及其状态是否与预期一致。
7. 执行完成后展示成功、失败和跳过的文件数量。
8. 记录操作历史。

默认建议优先提供隔离操作，不要默认永久删除文件。

如果实现永久删除功能，应将其与隔离区操作明确区分，并提供更严格的确认步骤。

### 6.7 隔离文件

按钮：

隔离

颜色：

使用中性或蓝色按钮，不使用危险红色。

行为：

1. 将用户选中的重复文件移动到应用专用隔离区。
2. 默认不隔离已标记为保留的文件。
3. 隔离前进行确认。
4. 在隔离区中保存原始文件路径、文件名、大小、SHA-256、隔离时间和必要的恢复信息。
5. 在跨磁盘移动时采用安全的复制、校验、提交、删除源文件流程。
6. 校验失败时保留源文件，并清理不完整的临时副本。
7. 更新重复文件分组和可释放空间统计。
8. 记录操作结果。

隔离区应采用专用目录，并避免被普通扫描任务重新扫描。

### 6.8 文件预览与详情

点击文件行或预览按钮后打开详情面板。

展示：

- 文件名。
- 完整路径。
- 文件大小。
- 创建时间和修改时间（系统能够获取时）。
- SHA-256。
- 所属重复文件组。
- 当前保留或隔离状态。
- 预览内容或系统默认打开操作。

不支持预览的文件应显示明确的类型信息，而不是显示错误图片。
