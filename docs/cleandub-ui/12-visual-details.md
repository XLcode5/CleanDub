## 十二、视觉细节与页面完成度

请特别注意以下细节：

1. 页面不能显得空洞，也不能将所有信息挤在一起。
2. 卡片边框和背景需要保持统一。
3. 主按钮统一使用 #0969DA。
4. 永久删除使用 #CF222E。
5. 表格行高保持一致。
6. 重要数字使用更明显的字重。
7. 辅助信息采用灰色小字号。
8. 所有文件类型图标保持统一风格。
9. 图片缩略图使用适当的固定尺寸，保持比例。
10. 侧边栏选中状态清晰但不过度突出。
11. 列表悬停时提供轻微背景变化。
12. 表格、弹窗、按钮和表单必须统一圆角规范。
13. 避免多余的大面积空白、无意义图表和装饰性插画。
14. 页面布局尽可能还原参考图中的 Windows 工具软件质感。
15. 不要将整个界面做成网页后台管理系统的通用模板。
16. 不要使用暗色主题。
17. 不要使用渐变背景或毛玻璃效果。
18. 不要在应用中加入与文件清理无关的营销内容。
