## 十三、开发阶段与执行顺序

请按照以下顺序完成工作。

### 阶段一：项目初始化

- 检查当前工作目录。
- 创建可运行的项目。
- 配置桌面容器、React、TypeScript 和样式系统。
- 建立统一设计 Token。
- 实现全局布局、侧边栏和窗口标题栏。

### 阶段二：完成三张核心页面

首先完成：

1. 首页。
2. 清理页。
3. 个人中心。

优先还原参考图的布局、卡片、配色、间距、文字层级和图标风格。

在接入真实业务前，可以使用明确标注的开发演示数据来验证 UI，但演示数据必须与正式运行模式分离，不得伪装成真实扫描结果。

### 阶段三：实现真实文件扫描

- 目录选择。
- 文件枚举。
- 文件大小分组。
- SHA-256 计算。
- 重复文件识别。
- 进度反馈。
- 取消扫描。
- 错误处理。
- 结果持久化。

### 阶段四：实现安全清理和隔离区

- 重复文件分组。
- 保留文件选择。
- 安全隔离。
- 永久删除确认。
- 文件预览。
- 文件恢复。
- 冲突处理。
- 操作日志。

### 阶段五：完成历史与设置

- 扫描历史。
- 历史详情。
- 隔离区统计。
- 隔离文件管理。
- 应用设置。
- 数据持久化。

### 阶段六：测试与交付

- 修复 TypeScript 错误。
- 修复 Rust 编译错误。
- 检查所有页面跳转。
- 检查文件选择和扫描。
- 检查取消扫描。
- 检查重复文件识别准确性。
- 检查隔离、恢复和永久删除。
- 检查应用重启后的数据持久化。
- 检查异常路径、权限不足和文件被占用的情况。
- 验证不同窗口尺寸下的布局。
- 如果环境允许，执行完整构建。

不要在完成某个阶段后就停止。必须持续推进到可交付状态。
