## 十四、测试要求

至少覆盖以下场景：

### 扫描功能

- 空目录。
- 没有重复文件的目录。
- 有多个重复文件的目录。
- 文件名不同但内容相同。
- 文件名相同但内容不同。
- 大文件。
- 无权限目录。
- 文件扫描期间被删除或修改。
- 多个扫描根目录。
- 取消扫描。
- 重启后查看历史记录。

### 清理功能

- 每组保留一个文件。
- 修改保留文件。
- 隔离多个文件。
- 清理前取消确认。
- 隔离失败。
- 文件在扫描后发生变化。
- 重复文件组内所有文件都被错误地选中。
- 同名文件恢复冲突。

### 隔离区功能

- 正常恢复。
- 恢复路径不存在。
- 原路径存在同名文件。
- 隔离文件损坏。
- 永久删除确认。
- 应用异常退出后重新启动。

对于危险操作，测试必须确保异常情况下不会错误删除用户的原始文件。
