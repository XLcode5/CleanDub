## 九、文件操作安全规范

这是一个会修改用户文件的工具，安全性必须优先于操作速度。

1. 默认不自动删除文件。
2. 不得未经用户确认执行批量永久删除。
3. 保留文件必须始终受到保护。
4. 不允许将隔离区目录作为普通扫描根目录。
5. 执行文件操作前重新验证文件是否存在。
6. 防止路径遍历和任意路径删除。
7. 对符号链接、权限不足、只读文件和文件占用情况进行妥善处理。
8. 不要直接信任前端提交的路径。
9. 后端必须自行验证文件路径、隔离区路径和允许执行的操作。
10. 跨磁盘移动必须进行内容校验。
11. 操作中断或应用崩溃时，不应导致源文件和目标文件同时丢失。
12. 不允许在校验失败时删除原始文件。
13. 批量操作应生成清晰的结果报告。
14. 使用最小必要权限，不要求管理员权限运行。
15. 所有文件操作应有明确的用户可见反馈。
16. 如果文件在扫描之后发生变化，应重新检查其大小、哈希或文件状态。
17. 对硬链接、符号链接、文件系统边界和重解析点制定明确处理策略。
18. 不要宣称任何清理方式绝对安全，应提供可理解的风险提示。

对于无法安全处理的文件，应跳过操作并说明原因，而不是强行执行。
