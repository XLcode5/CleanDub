## 四、应用全局结构

实现以下全局布局：

### 左侧导航栏

顶部：

- CleanDub 图标
- CleanDub 产品名称

导航菜单：

1. 首页
2. 清理
3. 个人中心

底部：

- 版本号，例如 v1.0.0
- 设置入口

要求：

- 当前页面使用浅蓝色背景和蓝色图标高亮。
- 未选中的菜单使用中性色。
- 点击菜单切换对应页面。
- 页面切换后保持整体布局稳定。
- 适当支持键盘导航。

### 顶部窗口区域

实现适合 Windows 桌面应用的标题栏。

如果使用 Tauri 或 Electron，正确配置窗口拖拽区域，并确保交互按钮不与拖拽区域冲突。

窗口关闭、最大化、最小化行为必须正常。

### 全局反馈系统

实现统一的 Toast 提示、确认对话框、错误提示和空状态组件。

禁止使用浏览器原生 alert 作为主要交互反馈。

危险操作必须经过明确的确认流程。
