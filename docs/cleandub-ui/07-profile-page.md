## 七、页面三：个人中心 — 扫描历史与隔离区

参考第三张 UI 概念图。

页面目标：管理历史扫描任务、查看处理记录、恢复隔离文件。

### 7.1 页面标题

个人中心

说明：

管理扫描历史与隔离区文件。

### 7.2 顶部统计卡片

第一张卡片：

扫描历史

展示：

- 历史扫描次数。
- 最近一次扫描时间。
- 累计扫描文件数。

第二张卡片：

隔离区文件

展示：

- 当前隔离文件数量。
- 隔离文件总大小。
- 可恢复文件数量。

以上统计必须从真实数据库数据计算，不能使用固定演示数字。

### 7.3 扫描历史表格

字段：

- 时间
- 扫描目录
- 扫描文件数
- 重复文件组数
- 扫描耗时
- 状态
- 操作

状态：

- 已完成
- 已取消
- 失败

操作：

- 查看详情
- 查看重复文件
- 删除历史记录

删除扫描历史记录不得自动删除真实文件，也不得误删隔离区数据。

历史记录支持排序和适当的分页。

点击历史记录可以查看当次扫描的详细信息。

### 7.4 隔离区管理卡片

标题：

隔离区管理

说明：

隔离区中的文件不会参与常规扫描，可在这里还原到原始位置或永久删除。

展示：

- 隔离文件数量。
- 隔离文件总大小。
- 最近一次隔离时间。
- 隔离文件列表入口。

按钮：

查看隔离区

点击后进入隔离区详情页面或打开完整隔离区管理视图。

### 7.5 隔离区详情页面

必须实际实现，不能只放一个空按钮。

展示：

- 文件名。
- 原始路径。
- 隔离时间。
- 文件大小。
- SHA-256。
- 当前状态。

操作：

恢复文件
永久删除
查看详情
选择多个文件
批量恢复
批量永久删除

恢复流程：

1. 检查原始路径是否仍然有效。
2. 检查原位置是否已存在同名文件。
3. 如果目标路径发生冲突，提示用户选择其他路径或取消恢复。
4. 恢复后验证文件完整性。
5. 只有确认恢复成功后，才更新隔离区记录。
6. 恢复失败时保留隔离文件。
7. 记录恢复操作结果。

永久删除流程：

1. 明确提示无法通过应用恢复。
2. 显示选中文件数量和文件名。
3. 要求用户再次确认。
4. 删除前验证隔离文件路径属于应用管理的隔离区。
5. 不允许将任意外部路径当作隔离文件直接删除。
6. 记录成功或失败状态。

### 7.6 设置入口

可以实现以下基础设置：

- 默认扫描目录。
- 是否包含隐藏文件。
- 是否跟随符号链接。
- 默认文件预览行为。
- 隔离区位置。
- 是否在清理前要求二次确认。

对于可能引起循环扫描、越权访问或大量重复遍历的选项，应提供合理限制和说明。
