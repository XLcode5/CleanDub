## 一、你的角色与开发目标

你是一名资深 Windows 桌面应用开发工程师、UI/UX 设计师和软件架构师。

请根据我提供的 CleanDub 三张 UI 概念参考图，实现一个真正可运行、界面精致、交互完整、具备实际文件处理能力的 Windows 桌面应用。

产品名称：CleanDub

产品定位：Windows 重复文件清理工具。

核心功能：扫描用户指定的文件夹，通过文件内容哈希识别重复文件，提供文件预览、重复文件分组、保留文件、清理文件、隔离文件、恢复文件、扫描历史和隔离区管理。

这不是一个静态网页，也不是只能演示的 UI 原型。最终交付必须是具有完整页面、真实交互、可执行文件操作和持久化数据的桌面应用。

**最高优先级：严格还原参考图的视觉风格，同时保证业务逻辑真实、文件操作安全、项目可以正常运行和构建。**

如果参考图中存在不合理的实现细节，可以优化内部架构，但不要擅自改变整体视觉设计方向。
