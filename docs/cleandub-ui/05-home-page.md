## 五、页面一：首页 — 扫描控制台

参考第一张 UI 概念图。

页面目标：让用户快速选择目录、启动扫描、查看实时进度和了解重复文件检测结果。

### 5.1 页面标题

标题：

重复文件清理工具

说明：

扫描指定目录，按文件内容找出重复文件，让你安全预览、清理或暂时隔离。

### 5.2 目录选择卡片

卡片标题：

选择扫描目录

包含：

- 当前目录路径输入框
- 选择目录按钮
- 支持添加多个目录
- 已添加目录列表
- 移除目录按钮
- 开始扫描按钮

交互要求：

1. 点击选择目录后，打开真实的 Windows 文件夹选择对话框。
2. 支持选择多个扫描目录。
3. 显示每个目录的完整路径。
4. 允许移除不需要的目录。
5. 扫描前验证目录是否存在及是否可访问。
6. 对权限不足、目录不存在等情况提供明确错误信息。
7. 默认排除应用自身的隔离区目录，避免扫描隔离文件产生重复记录。
8. 对多个目录中的重复文件进行统一识别。
9. 不得未经用户授权擅自扫描整个系统盘。

### 5.3 扫描原理说明卡片

标题：

智能识别重复文件

展示以下说明：

- 基于文件内容的 SHA-256 哈希识别重复文件。
- 支持常见图片、视频、文档及其他文件类型。
- 清理前可以预览文件并确认处理方式。
- 支持将文件移动到隔离区，方便后续恢复。

可使用简洁的文件、搜索和校验图标。

不要用复杂插画或大面积装饰占用空间。

### 5.4 扫描进度卡片

标题：

扫描进度

展示：

- 当前扫描状态。
- 扫描目录。
- 环形进度指示器。
- 水平进度条。
- 已检查文件数量。
- 已发现重复文件数量。
- 已处理文件数量。
- 扫描耗时。
- 当前正在处理的文件名称，可截断长路径。

扫描状态包括：

- 空闲
- 正在枚举文件
- 正在计算哈希
- 正在识别重复文件
- 扫描已完成
- 扫描已取消
- 扫描失败

要求：

- 进度数据必须来自真实扫描任务。
- 扫描期间实时更新界面。
- 如果总文件数尚未确定，显示不确定进度，而不是伪造百分比。
- 支持取消扫描。
- 取消后保留已获取的必要扫描记录，并明确标注任务已取消。
- 扫描完成后更新统计数据。

### 5.5 扫描结果摘要卡片

展示：

- 已扫描文件总数。
- 发现的重复文件组数。
- 可释放空间估算。
- 最近一次扫描时间。

提供蓝色主按钮：

查看清理结果

点击后进入清理页面。

注意：可释放空间必须按照实际重复文件组和建议保留策略计算，避免将每个重复文件都重复计入。

### 5.6 首页状态设计

首次启动：

显示清晰的空状态和选择目录提示。

扫描中：

显示真实进度、当前文件和取消按钮。

扫描完成：

显示实际统计结果及进入清理页的按钮。

没有重复文件：

显示成功状态和“未发现重复文件”的说明。

发生错误：

展示具体错误信息及重试操作。
