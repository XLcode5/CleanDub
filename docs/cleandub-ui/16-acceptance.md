## 十六、最终验收标准

最终应用必须同时满足以下要求：

- [ ] 具有完整的 Windows 桌面应用布局。
- [ ] 视觉风格与三张参考图保持一致。
- [ ] 包含首页、清理页、个人中心。
- [ ] 包含完整的隔离区管理界面。
- [ ] 能够真实选择本地目录。
- [ ] 能够通过 SHA-256 识别重复文件。
- [ ] 能够展示真实扫描进度。
- [ ] 能够预览支持的文件类型。
- [ ] 能够指定保留文件。
- [ ] 能够安全隔离重复文件。
- [ ] 能够恢复隔离文件。
- [ ] 能够在确认后永久删除隔离文件。
- [ ] 能够查看扫描历史。
- [ ] 数据在应用重启后仍然存在。
- [ ] 危险操作具有完整的确认与异常处理机制。
- [ ] 所有核心按钮均具有实际功能。
- [ ] 没有明显的布局溢出、占位页面或虚假统计。
- [ ] 项目能够启动，并在目标环境支持时完成 Windows 构建。

**现在开始检查开发环境并创建项目。优先交付可运行的真实应用，而不是停留在方案设计或静态 UI 演示阶段。请根据实际开发进度逐步实现、运行、测试、修复并最终交付。**
