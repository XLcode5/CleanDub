## 三、整体视觉设计规范

严格参考提供的三张 CleanDub UI 概念图。

设计方向：Windows 11 设置界面的秩序感 + GitHub 网页端的简洁工具风格。

关键词：

- 极简
- 专业
- 高信息密度但不拥挤
- 浅色桌面应用
- 清晰的视觉层级
- 卡片式布局
- 扁平化设计
- 精细的边框与间距
- 原生 Windows 工具感
- 高质量商业软件视觉

### 3.1 配色系统

统一使用以下颜色：

- 应用主背景：#F6F8FA
- 卡片背景：#FFFFFF
- 主蓝色：#0969DA
- 主蓝色悬停：#0550AE
- 危险操作：#CF222E
- 危险操作悬停：#A40E26
- 成功状态：#1A7F37
- 警告状态：#9A6700
- 主要文字：#1F2328
- 次要文字：#59636E
- 边框：#D1D9E0
- 分隔线：#EAECEF
- 次级背景：#F6F8FA
- 选中背景：#DDF4FF

禁止使用渐变、毛玻璃、霓虹发光、重阴影、过度装饰、3D 图标和不必要的渐变色按钮。

### 3.2 布局规范

- 以 Windows 桌面应用为目标，不要设计成移动端网页。
- 基准设计画布：1440 × 900。
- 推荐默认窗口大小：1280 × 800。
- 最小可用窗口尺寸：1024 × 680。
- 页面应随窗口尺寸合理调整，不得出现主要操作按钮被裁切的情况。
- 左侧固定导航栏，右侧为主要工作区域。
- 导航栏宽度约 160–180px。
- 主内容区域采用明确的网格布局。
- 卡片圆角统一为 8px。
- 卡片使用 1px 细边框。
- 阴影应极轻，优先通过边框区分层级。
- 页面主内容内边距约 16–24px。
- 卡片之间间距约 12–16px。
- 使用统一的间距、字体、边框和按钮尺寸规范。

### 3.3 字体与图标

- 中文优先使用 Microsoft YaHei UI、Microsoft YaHei 或系统默认中文字体。
- 英文及数字可使用 Segoe UI。
- 标题、正文、辅助信息要形成清晰的字号层级。
- 页面标题约 22–26px。
- 卡片标题约 14–16px。
- 正文约 13–14px。
- 辅助文字约 11–12px。
- 图标统一使用 Lucide React 线性图标。
- 常规图标尺寸 16–20px。
- 图标线条粗细保持一致。
- 不要混用 Emoji 作为正式功能图标。

### 3.4 交互状态

所有控件需要提供：

- 默认状态
- 悬停状态
- 按下状态
- 键盘焦点状态
- 禁用状态
- 加载状态
- 成功、失败或警告反馈

交互设计应接近成熟的 Windows 桌面工具，避免夸张动画。

允许使用轻量级过渡动画，时长约 120–180ms。
