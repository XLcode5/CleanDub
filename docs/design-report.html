设计理念

整体设计借鉴 VS Code、Linear、GitHub Dark 等现代化工具的视觉语言，追求克制、清晰、高效的桌面应用体验。

设计原则体现
减少视觉噪音无彩色装饰，单一蓝色强调色，灰阶背景层次
信息密度适中卡片化分区，统计一行四栏，设置集中面板
即时反馈自定义进度条、按钮三态 (normal/hover/pressed)、侧栏激活指示条
暗色优先深色为默认，眼睛友好；浅色主题完整支持一键切换
语义化配色12 个色变量覆盖全部 UI 状态，无硬编码色值散落

核心自定义控件

全部控件通过 GDI+ (System.Drawing.Drawing2D) 自绘，彻底摆脱 WinForms 原生控件的直角、粗边框风格。

控件类型特性
ModernButton 自定义 Button GDI+ 自绘，圆角 8px，三态动画 (normal/hover/pressed)，支持 填充 / 幽灵 (ghost) / 危险 (danger) 三种样式，禁用态灰显
SidebarButton 自定义 Control 左侧 3px 蓝色激活指示条，激活时圆角背景高亮，hover 半透明过渡
CustomProgressBar 自定义 Control 自绘圆角进度条，蓝色填充 + 深色轨道，无 WinForms 原生锯齿，0-100% 平滑
统计卡片 Panel (Owner-Draw) 10px 圆角 + 1px 边框 + 表面色填充，每张 190×74px，标签在上数值在下
设置卡片 Panel (Owner-Draw) 12px 圆角 + 1px 边框，内含输入控件和操作按钮
ListView Owner-Draw ListView 隔行交替变色，选中行蓝色高亮，复选框区域独立背景
RoundedRectangle Graphics 扩展方法 FillRoundedRectangle / DrawRoundedRectangle 通用 GDI+ 圆角绘制

ModernButton 样式变体

样式设置效果使用场景
Fill AccentAccentColor=true, IsGhost=false蓝底白字，hover 亮蓝，圆角 8px主操作按钮（开始扫描）
GhostAccentColor=true, IsGhost=true透明背景 + 文字色，hover 显示浅色底次要操作（浏览、导出）
DangerAccentColor=true, _isDanger=true红底白字，hover 亮红危险操作（永久删除、终止）
